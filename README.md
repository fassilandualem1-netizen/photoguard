# PhotoGuard - Android Client
A production-ready Android app for secure photo album delivery.

## Project Structure
Generated by `generate.py`. Run `python generate.py` to scaffold the full project.

## CI/CD
GitHub Actions automatically builds the Release APK on every push to `main`.
Download the APK from the **Actions → Artifacts** tab.

## Features
- 🔒 FLAG_SECURE anti-screenshot protection
- 📦 R8 full minification (<5 MB target)
- 🧭 Compose NavHost: Login → Gallery → Delivery
- 🌐 Retrofit + OkHttp secure networking
- 🖼️ RAM-only Coil image pipeline (no disk cache)
